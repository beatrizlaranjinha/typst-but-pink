♡ Getting started

Make sure you have [Typst installed](https://github.com/typst/typst#installation). On macOS, you can use:

```bash
brew install typst
```

Clone the project and compile the example report:

```bash
git clone https://github.com/beatrizlaranjinha/typst-but-pink-.git
cd typst-but-pink-
typst compile main.typ
```
